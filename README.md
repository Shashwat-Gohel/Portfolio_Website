# Portfolio OS X | Shashwat Gohel

A high-fidelity, macOS-inspired digital architecture designed to showcase technical precision and creative engineering. This portfolio leverages a sophisticated terminal/finder app aesthetic to deliver an immersive, immersive developer experience.

![Portfolio Preview](/public/assets/preview.png) *(Note: Add a high-res screenshot to public/assets/preview.png for absolute polish)*

## 🖥️ System Architecture

Built on a micro-navigation framework, the platform simulates a complete desktop environment with functional windowing systems, real-time terminal reveals, and an edge-to-edge communication node.

### Core Modules
- **Project Finder (Work Archive)**: A categorized project repository (SDE, AI/ML) using a high-aesthetic macOS folder grid.
- **Stack Log (Terminal)**: A dynamic, typing-simulated terminal console that reveals technical proficiencies and system capabilities.
- **Mail.app (Contact Node)**: A full-screen, translucent contact interface with automated dispatch handoffs and social identity nodes.
- **Experience Node**: A streamlined professional timeline with interactive role exploration windows.

## 🛠️ Tech Stack foundations

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router Architecture)
- **Language**: [TypeScript](https://www.typescriptlang.org/) (Type-safe implementation)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) (Atomic Design System)
- **Animations**: [Framer Motion](https://www.framer.com/motion/) (High-fps transitions & draggability)
- **Icons**: [Lucide React](https://lucide.dev/) & Custom SVGs (Retina-ready geometry)

## 🚀 Getting Started

Ensure you have **Node.js (>= 18.17.0)** installed on your system kernel.

### 1. Repository Synchronization
```bash
git clone https://github.com/ShashwatGohel/Portfolio_Website.git
cd Portfolio_Website
```

### 2. Dependency Resolution
```bash
npm install
# or
yarn install
```

### 3. Launch Development Node
```bash
npm run dev
```

The system will be initialized at `http://localhost:3000`.

## 📂 Configuration Mapping

- `src/lib/projectData.ts`: Central registry for work archive metadata.
- `src/lib/stackData.ts`: Definitions for technical skills and terminal reveals.
- `src/components/work/`: Core logic for the MacBook shell and windowing system.
