# Certifications Vault

Upload your certification files (PDF, JPG, PNG) here to display them on your portfolio.

## naming Convention
To ensure the automated links work correctly:
1. Save your file as `[certificate_id].pdf` (e.g., `aws-cloud-practitioner.pdf`)
2. Update the `id` in `src/lib/projectData.ts` to match the filename.

## Integrated Certificates
The system is currently configured to look for these files in this directory.
